Making Everyday Communication Easier

Use a camera, microphone, or text file to move between supported hand signs, readable text, and spoken audio.

About Connect B-DM

Connect B-DM is a browser-based accessibility project built to demonstrate three practical communication tools. It can recognize supported alphabet hand signs through a webcam, turn a short voice recording into text, and display text one character at a time using sign reference images. The project keeps each feature simple so users can clearly see how the input is captured, processed, and presented.

Sign to Text and Voice

The webcam tracks one hand and sends its landmark points to the trained model. A detected letter can be added to the text box and then played or saved as speech.

Voice to Text

Record a short message through the microphone. The server prepares the audio, sends it for speech recognition, and shows the returned text on screen.

Text Interpreter

Upload a plain text file and step through it at your own pace. Letters are shown with the available sign images, while completed words are displayed between spaces.

How It Works

Each tool follows the same straightforward flow: provide an input, let the system process it, and review the result.

1

Choose an Input

Show a supported hand sign to the webcam, record a voice message, or select a text file from your computer.

2

Process the Input

The project uses hand landmarks and a trained model for signs, audio preprocessing and speech recognition for voice, or stored images for text.

3

Review the Output

Read the recognized text, listen to generated speech, save a message, or move through the sign references one character at a time.
